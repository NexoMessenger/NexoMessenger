# Презентация: реактивное движение в жизни и в технике

Физика, четверг, 26 ноября 2026. 8 слайдов: простое объяснение, 3 формулы с разбором букв, примеры из жизни и техники, короткий итог. Картинки на каждом смысловом слайде.

## Файлы

- `index.html` — презентация в браузере. Листать стрелками `←` / `→`, пробелом или свайпом. `F` — на весь экран.
- `reaktivnoe-dvizhenie.pptx` — тот же текст, картинки и формулы в PowerPoint / Google Slides. Внутри есть заметки для рассказа.
- `shpargalka.md` — что сказать на каждом слайде за 3–4 минуты.
- `assets/` — картинки для слайдов.

Кнопка **«Печать / PDF»** в браузере сохраняет все слайды в PDF. Интернет не нужен: всё лежит рядом с файлами.
