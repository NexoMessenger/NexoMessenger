# Презентация: реактивное движение в жизни и в технике

Физика, четверг, 26 ноября 2026. 8 слайдов, простые слова, примеры из жизни, картинки.

## Файлы

- `index.html` — презентация в браузере. Листать стрелками `←` / `→`, пробелом или свайпом. `F` — на весь экран.
- `reaktivnoe-dvizhenie.pptx` — тот же текст и картинки в PowerPoint / Google Slides. Внутри есть заметки для рассказа.
- `shpargalka.md` — что сказать на каждом слайде за 2–3 минуты.
- `assets/` — картинки для слайдов.

Кнопка **«Печать / PDF»** в браузере сохраняет все слайды в PDF. Интернет не нужен: всё лежит рядом с файлами.
