# Инструкция: установка и проверка RustLike (этап 1)

Инструкция для Windows. Никаких паролей, ключей и кодов подтверждения
от вас не требуется — только скачивание официальных программ.

---

## 1. Что скачать

1. **Папку проекта** `rustlike` (этот мод) — из Arena или из GitHub:
   - репозиторий `NexoMessenger/NexoMessenger`,
   - ветка `arena/faf605bf-nexomessenger`,
   - папка `rustlike/` в корне.
2. **Java 17 (JDK)** — Temurin 17: https://adoptium.net/temurin/releases/
   (файл `OpenJDK17U-jdk_x64_windows_hotspot_17.x.x_x.msi` — версия .msi).
3. **Minecraft Java Edition** — официальный лаунчер:
   https://www.minecraft.net/download
4. **Forge для 1.20.1** — https://files.minecraftforge.net/net/minecraftforge/forge/index_1.20.1.html
   (кнопка «Installer», версия 47.x, например 47.3.0).
5. *(Необязательно)* **Python 3** — https://www.python.org/downloads/
   только если хотите запустить автопроверку проекта.

## 2. Установка Minecraft Java 1.20.1

1. Установите Minecraft Launcher и войдите в свой аккаунт Minecraft
   (тот, на который куплена игра).
2. В лаунчере нажмите «Установки» (Installations) → «Создать»:
   - Версия: **release 1.20.1**
   - Имя: любое, например `1.20.1`
3. Нажмите «Играть» один раз — игра скачает файлы и дойдёт до главного
   меню. Это обязательно: Forge установится поверх этих файлов.
4. Выйдите из игры.

## 3. Установка Forge

1. Запустите скачанный файл `forge-1.20.1-47.x.x-installer.jar`
   (двойной клик; если не открывается — ПКМ → Открыть с помощью → Java).
2. Выберите **Install client** и нажмите OK
   (путь по умолчанию `%appdata%\.minecraft` — не меняйте).
3. Дождитесь надписи «Successfully installed…» и закройте окно.
4. Проверка: запустите Minecraft Launcher — должен появиться профиль
   **forge-1.20.1**. Выберите его и нажмите «Играть» до главного меню,
   затем выйдите.

## 4. Нужна ли Java и какая именно

- **Да, Java 17 (JDK 17)** — нужна для **сборки мода** (пункт 6).
- Установите Temurin JDK 17 из пункта 1 (файл .msi, в установщике
  оставьте галочку добавления в PATH / установки JAVA_HOME).
- Проверка: откройте «Командную строку» (Win+R → `cmd`) и введите:
  ```
  java -version
  ```
  Должно появиться `version "17.x"`.
- Для самой игры отдельная Java не обязательна — лаунчер использует
  встроенную. Но без JDK 17 не соберётся `.jar` (пункт 6).

## 5. Как получить проект или готовый `.jar`

- **Проект (исходники):** скачайте папку `rustlike` (см. пункт 1)
  и положите, например, в `Документы\rustlike`.
- **Готовый `.jar`:** если вы уже собрали его (пункт 6) — файл
  `rustlike\build\libs\rustlike-0.1.0.jar`. Если сборка не выполнялась
  — готового `.jar` НЕ существует, только исходники; переходите на пункт 6.

## 6. Как собрать `.jar`

1. Откройте папку `rustlike` (где лежит `gradlew.bat`).
2. В строке адреса проводника введите `cmd` и нажмите Enter
   (откроется командная строка в этой папке).
3. Введите:
   ```
   gradlew.bat build
   ```
4. Первая сборка длится 5–15 минут (скачивает Forge и Minecraft,
   нужно ~500 МБ интернета). Не закрывайте окно.
5. **Если появилась ошибка:** сохраните весь текст окна целиком
   (ПКМ → Выделить всё → Enter — текст скопируется) и пришлите его мне.
   Частые причины: не установлена Java 17 (пункт 4), нет интернета.
6. **Если всё прошло:** файл появится здесь:
   `rustlike\build\libs\rustlike-0.1.0.jar`
   *(только этот файл — не `sources` и не `slim`, если они будут.)*

## 7. В какую папку положить мод

1. Найдите папку игры: Win+R → введите `%appdata%\.minecraft` → Enter.
2. Внутри создайте папку `mods` (если её нет).
3. Положите в `mods` файл **`rustlike-0.1.0.jar`**.
4. Убедитесь, что в `mods` не лежат моды для других версий Minecraft
   (моды 1.20.1 совместимы, остальные — нет). Для чистой проверки
   оставьте в `mods` только наш `.jar`.

## 8. Как запустить игру

1. Откройте Minecraft Launcher.
2. Выберите профиль **forge-1.20.1** (создан в пункте 3).
3. Нажмите **«Играть»**.
4. На главном экране нажмите кнопку **«Моды»** — в списке должен быть
   **RustLike** (версия 0.1.0). Это подтверждает, что мод загружен.

## 9. Как создать тестовый мир

1. «Одиночная игра» → «Создать новый мир».
2. Режим игры: **Творческий** (для быстрой проверки; выживание тоже
   подходит, но ресурсы придётся добывать).
3. Тип мира: **Суперплоский** (удобно смотреть постройки).
4. Остальные настройки — по умолчанию → «Создать новый мир».
5. Первым делом нажмите `T` и введите команду (включает подсказки):
   ```
   /gamemode creative
   ```
   (в творческом режиме не нужна).

## 10. Как получить предметы и проверить строительство

**Получение предметов** — откройте инвентарь (`E`):
- вкладка **«Строительные блоки»**: Фундамент, Стена, Дверной проём;
- вкладка **«Инструменты»**: Строительный план, Молоток.

Или командами (через `T`):
```
/give @s rustlike:building_plan
/give @s rustlike:hammer
/give @s rustlike:foundation 64
/give @s rustlike:wall 64
/give @s rustlike:doorway 64
/give @s rustlike:stick 64
```

**Проверка по порядку:**

1. **План в руке → ПКМ** — открылось круговое меню?
2. Выберите **Фундамент** (навести + ЛКМ или цифра `1`) → меню закрылось.
3. Наведитесь на землю — под прицелом **зелёная рамка**? (красная —
   прочитайте причину в HUD сверху слева).
4. **ЛКМ** — фундамент поставлен (палки списались)?
5. Выберите **Стену** (`2`) → поставьте **на фундамент или рядом** —
   рамка зелёная? (на земле в одиночку стена даёт красную «нужна опора» —
   это правильно, стена ставится на фундамент).
6. Поставьте два-три фундамента в ряд, стены вокруг, в одной из стен
   **Дверной проём** (`3`).
7. Выберите **Дверь** (`4`) → наведитесь **на проём** → ЛКМ.
   Наведитесь на дверь **без плана** → **ПКМ** — дверь открылась/закрылась?
8. **Молоток в руке → ПКМ по постройке** — открылся экран с материалом
   и полосой прочности? Нажмите **«Улучшить»** (нужны палки/доски и т.д.
   — в творческом не тратятся) — уровень изменился (текстура стала
   ярче/другой)?
9. **Ремонт:** вызовите кридера рядом (`/summon creeper`) и отойдите —
   взрыв нанёсёт урон (полоса в молотке уменьшится, рамка постройки
   не исчезнет!) → молоток → «Починить».
10. **Сохранение:** выйдите из мира, зайдите снова — все постройки
    на месте? Откройте/закройте дверь — состояние сохранилось?

## 11. Что делать, если игра не запускается

1. **Сначала посмотрите журнал:** в лаунчере при запуске нажмите
   «Играть» → если игра падает, откройте файл
   `%appdata%\.minecraft\logs\latest.log`.
2. Проверьте по очереди:
   - выбран профиль **forge-1.20.1**, а не «latest»;
   - в `mods` лежит только `rustlike-0.1.0.jar` (временно уберите
     другие моды — часто конфликт именно из-за них);
   - установлена Java 17 (пункт 4);
   - версия мода для 1.20.1 (в названии `.jar` — `0.1.0`, версия игры —
     1.20.1; мод для 1.20.2+ не подойдёт).
3. **Если сборка упала** (пункт 6): пришлите весь текст `gradlew.bat build`.
4. Не удаляйте ничего из `.minecraft` вручную, кроме проблемного `.jar`.

## 12. Какие скриншоты и журналы прислать

Присылайте мне (в чат):

1. **Если игра не стартует:** скриншот ошибки лаунчера + файл
   `logs\latest.log` целиком (можно просто перетащить файл в чат).
2. **Если сборка падает:** полный текст команды `gradlew.bat build`
   (все строки, особенно `error:` / `FAILURE:`).
3. **Если мод загрузился, но что-то не так:** скриншот того места
   (круговое меню, превью, дверь, экран молотка, HUD) + тот же
   `latest.log`.
4. **Что проверилось хорошо:** короткий список «работает/не работает»
   из пункта 10 — это поможет двигаться к этапу 2.
