# RustLike — Rust внутри Minecraft 1.20.1 (Forge)

Мод, постепенно переносящий игровой опыт **Rust** в **Minecraft Java Edition 1.20.1 + Forge**.
Проект создан для личного использования. Все объяснения — по-русски.

## Что умеет этап 1

### Строительный план
- ПКМ с планом в руке — **круговое меню** (4 сектора: фундамент, стена, проём, дверь)
- Выбор мышью, цифрами 1–4 или Enter; подсказка с названием и стоимостью
- **Превью под прицелом**: зелёная рамка — можно поставить, красная — нельзя
- Причина отказа видна сразу («Здесь занято», «Сначала поставь фундамент…» и т.д.)
- ЛКМ — установка выбранного элемента с **расходом ресурсов** (палки, настраиваются)

### Элементы и связность
- Квадратный фундамент (плита) — ставится только на твёрдую опору
- Стена — ставится на фундамент или впритык к постройке
- Дверной проём — как стена, с рамой и направлением «куда смотрит»
- Дверь — ставится **только в пустой проём**, открывается/закрывается ПКМ
  (звук зависит от материала: дерево — деревянная дверь, камень+ — железная)

### Уровни строительства (5)
`Ветки → Дерево → Камень → Металл → Улучшенный металл`
- Своя текстура, прочность и устойчивость к взрывам у каждого уровня
- Новая постройка начинается с уровня «Ветки»

### Молоток
- ПКМ по постройке — экран: материал, уровень, полоса прочности
- **Ремонт** за ресурсы текущего уровня (урон накапливается от взрывов)
- **Улучшение** до следующего уровня за ресурсы следующего уровня
- Проверка наличия ресурсов и расстояния — на сервере

### Мир и сохранение
- Постройки хранятся в мире (переживают выход и перезапуск)
- Крипер/TNT больше **не разрушают** постройки мгновенно — наносят урон
  (чем выше уровень, тем меньше урон), постройку чинят молотком
- Взрывоопасность настраивается в `config/rustlike-common.toml`

## Как играть (этап 1)

| Действие | Клавиша |
|---|---|
| Открыть круговое меню строительства | **ПКМ** с планом в руке |
| Выбрать элемент в меню | **ЛКМ** / **Enter** / цифры **1–4** |
| Установить элемент под прицелом | **ЛКМ** с планом в руке |
| Открыть/закрыть дверь | **ПКМ** по двери (голыми руками или предметом) |
| Осмотреть/починить/улучшить постройку | **ПКМ** по постройке **молотком** |
| Закрыть экран | **Esc** |

**Порядок строительства:** фундамент на землю → стены/проёмы на фундамент или
друг к другу → дверь в проём → молоток для ремонта/улучшения.

**Ресурсы этапа 1:** палки (установка), палки/доски/булыжник/железо/алмазы
(ремонт и улучшение — по уровню). В творческом режиме ресурсы не тратятся
(настройка `skipCostsInCreative`).

## Структура проекта

```
rustlike/
├── build.gradle, settings.gradle, gradle.properties   ← сборка Forge
├── gradlew, gradlew.bat, gradle/wrapper/              ← Gradle 8.1.1 wrapper
├── INSTRUKCIYA_RU.md      ← инструкция установки (12 пунктов)
├── ROADMAP_RU.md          ← дорожная карта всех этапов
├── README_RU.md           ← этот файл
├── tools/
│   ├── generate_assets.py ← генератор текстур/моделей/blockstate
│   └── validate_project.py← автопроверка проекта
└── src/main/
    ├── java/dev/rustlike/
    │   ├── RustLikeMod.java        ← главный класс мода
    │   ├── ModRegistry.java        ← реестр блоков/предметов
    │   ├── RustConfig.java         ← настройки (config/rustlike-common.toml)
    │   ├── piece/                  ← PieceType, StructureTier (5 уровней)
    │   ├── block/                  ← фундамент, стена, проём, BlockEntity
    │   ├── item/                   ← строительный план, молоток
    │   ├── logic/                  ← правила установки, ремонт/улучшение
    │   ├── network/                ← пакеты клиент↔сервер
    │   ├── client/                 ← круговое меню, экран молотка, превью, HUD
    │   └── event/                  ← взрывы, творческие вкладки
    └── resources/
        ├── META-INF/mods.toml, pack.mcmeta
        ├── assets/rustlike/        ← lang, текстуры, модели, blockstates (114)
        └── data/rustlike/loot_tables/blocks/  ← выпадение блоков
```

## Сборка и проверка (на своём ПК)

```bat
cd rustlike
gradlew build
python tools\validate_project.py     (необязательно, если есть Python)
```

Готовый файл: `build\libs\rustlike-0.1.0.jar` — положите в папку `mods`
вашего профиля Forge. Подробности — в `INSTRUKCIYA_RU.md`.
