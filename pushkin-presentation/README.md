# А. С. Пушкин — жизнь и творчество

Готовый материал к уроку литературы: 12 слайдов + заметки для выступающего.
Тёмная «музейная» тема, золото, репродукции картин (Кипренский, Репин, Ге, Брюллов).

## Файлы

| Файл | Что это |
| --- | --- |
| `Pushkin-prezentaciya.pptx` | Презентация для PowerPoint / Google Slides / Keynote. 16:9, 12 слайдов, переходы «Плавное появление» + анимации появления элементов, заметки для выступающего. |
| `Pushkin-prezentaciya.html` | Та же презентация в браузере: один автономный файл (картинки встроены), работает офлайн, с красивыми анимациями, свайпами и полноэкранным режимом. |
| `assets/` | Репродукции картин (используются при сборке). |
| `build_pptx.py`, `add_animations.py`, `build_html.py` | Скрипты сборки, если нужно что-то поправить. |

## Как показывать

**HTML-версия (самая красивая):** открыть файл в браузере, нажать «⛶» для полного экрана.
Управление: `←` `→` или пробел, колесо мыши, свайп на телефоне, точки внизу — переход к слайду.

**PPTX:** обычный режим показа (F5). Элементы появляются по очереди по клику —
если нужен спокойный вариант, просто пролистывайте слайды стрелками.
Заметки для выступающего: «Вид → Заметки» (Speaker Notes).

## О чём презентация

1. Титул
2. Почему Пушкин — «наше всё»
3. Детство и Царскосельский лицей (1799–1817)
4. Петербург и южная ссылка (1817–1824)
5. Михайловское: два года в тишине (1824–1826)
6. Болдинская осень (1830)
7. Дом, семья, Петербург (1831–1837)
8. Что читать в первую очередь
9. Дуэль на Чёрной речке (1837)
10. Наследие
11. Пять дат, которые стоит запомнить
12. Финал

## Пересобрать

```bash
python3 -m pip install --break-system-packages python-pptx pillow
python3 build_pptx.py        # → pptx
python3 add_animations.py    # → переходы и анимации появления
python3 build_html.py        # → автономный html
```
